# EasyBill - Smart Bill Splitting App

EasyBill is a modern, intuitive app that simplifies splitting bills with friends. Take a photo of your receipt, assign items to people, and get instant calculations.

## Features

- 📸 **Photo Capture**: Upload or take photos of receipts
- 👥 **User Management**: Add up to 8 people to split bills
- 🎯 **Smart Allocation**: Assign items individually or share them
- 💰 **Instant Calculations**: See exactly what each person owes
- 🎨 **Beautiful UI**: Modern, responsive design with smooth animations

## Tech Stack

- React 18 with TypeScript
- Vite for fast development
- Tailwind CSS for styling
- Shadcn/ui components
- React Router for navigation

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
